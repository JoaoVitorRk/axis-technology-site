# AXIS Precision Foot Technology · prévia do site

Prévia feita pela RK Performance (https://rkperformance.com.br). Página única em `index.html`, cena 3D em `axis3d.js` (three.js pelo jsDelivr) e mídia em `media/`.

- Abertura: vídeo em loop (`media/hero-16x9.mp4` no computador, `media/hero-9x16.mp4` no celular). Se o vídeo não carregar, entra a cena 3D; `?hero=3d` força a cena 3D.
- Prévia com `noindex` e `robots.txt` bloqueando buscadores até a aprovação do cliente.
